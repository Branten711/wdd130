Client Report

The team that developed my site were very easy to work with and they did a great job communicating with me. I wanted to make a site that would be beneficial for me to research and learn more about, so that is how I decided the content. The pictures were not as important to me. The information that the site provided was the most important thing to me. It was hard to communicate because we all have different schedules. I feel like it would be beneficial to have met in person, but since that was a limiting factor, it went well despite that. What I would do differently next time is meet in person.

Lead Developer Report

We used Microsoft Teams to communicate for this project, since this is an online course. This made it difficult at some points to communicate with others because everyone on the team developing the site had different schedules or didn't participate in the chat. We also communicated with the client using Microsoft Teams. This created some delay in receiving feedback, but we worked through the communication issues. We sent the site link to the client through a chat on Teams with the whole team so they could provide feedback. We had a GitHub repository that the project was managed through. This made it easy for us all to make changes and add features that the client wanted. In the end, we created a product that the client was happy with.

Junior Developer Report

In this project, we had a Microsoft Teams chat with all team members, including myself, that we would use to communicate with the team lead. There was good communication this way. I had a good idea of what was expected, and if I had questions, I could ask the chat and get an idea of what the client was looking for and contribute those changes to the site. The team leads both did a good job of setting up the repo on GitHub so that changes were easy to make. This made adding my work to the site quick and easy.

General Experience and Reflections

I would say that this project was a great experience for me because it helped me to see all of the different challenges that can be associated with a project like this. One of those is communicating virtually with a team or even the client. This can create delays or lack of understanding of what is expected or wanted on the site. There were also great parts of the project, like working to create something that someone values or even needs. It was cool to solve or create a project for real-world application. This project would have definitely benefited from face-to-face interaction with the team and the client. All that said, through this experience, I can say that I feel more confident working on real-world projects.
